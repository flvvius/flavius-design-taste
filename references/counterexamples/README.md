# Counterexamples

A counterexample can be competent and still miss this practice. Record its source, license, date, task and specific mismatch. Compare its hierarchy and behavior before judging taste. Keep real output captures with the public app evaluation that produced them; do not pretend a fabricated mockup is Lovable, Bolt or v0 output.
