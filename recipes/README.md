# Portable recipes

These components adapt implemented work, with each source and limitation beside its snippet. The settings and collection patterns come from this repository's v1 specimens. The ink and case-study patterns come from the portfolio. Standing heads, rails and reusable task instructions come from Pricele. None is a third direction.

Use a recipe after discovery and the behavior contract. Replace demonstration state with the client's existing callbacks. A snippet is not permission to change a flow.
