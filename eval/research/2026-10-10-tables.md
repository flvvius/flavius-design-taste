# Readable chart values at narrow widths

Cycle 21 left a visible problem in its otherwise passing chart checks. At 320px, table headers could split within words. Enlarged text made the fragments more pronounced. The [cycle 22 baseline](../cycles/22/before/checks.json) records multiple lines for each single-word header. A separate run with scripts disabled had no total and no data rows.

## USWDS source review

Reviewed the USWDS table styles at revision `029d6d792241b3b4107a630590a27ee951a152b5` on 10 October 2026: [the component entry point](https://github.com/uswds/uswds/blob/029d6d792241b3b4107a630590a27ee951a152b5/packages/usa-table/src/styles/_usa-table.scss) and [the table mixins](https://github.com/uswds/uswds/blob/029d6d792241b3b4107a630590a27ee951a152b5/packages/uswds-core/src/styles/mixins/general/table.scss). The entry point applies stacked variants below a breakpoint. The mixin hides the header row, displays cells as blocks and supplies repeated labels from `data-label` through generated content.

The [published guidance](https://designsystem.digital.gov/components/table/) distinguishes stacked layouts for text-heavy rows from scrollable layouts for dense comparisons. Its update history also records a Safari and VoiceOver correction for stacked content. That history is a reason to inspect semantics when changing table display rules. It does not establish an accessibility failure in this repository's current browser builds.

For this example's two counts per bucket, the chosen narrow view uses ordinary headings and definition lists. Series labels and dates are real text. The comparison table retains native table display on wider screens. CSS exposes one representation at a time, and both receive the same period data. This decision takes the reading pattern from the study without importing USWDS, its Sass tooling or its visual styling.

## Alternatives and limits

[W3C reflow guidance](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) allows two-dimensional scrolling for data that needs that structure, while keeping other page content readable. A scrollable table remains appropriate for dense cross-column comparison. The [GOV.UK table guide](https://design-system.service.gov.uk/components/table/) also discusses splitting large data sets and reducing text size at small widths. This fixture has only four or seven buckets, and enlarged text must remain usable. Labelled pairs address the observed pressure without changing font sizes or discarding data.

The default week is now present in the HTML. Period changes update the chart, table and paired values together. The controls remain disabled until script initialization completes. Separate script-disabled runs check both reading layouts, spacing, forced colours and enlarged fallback typography after font requests fail.

Script-disabled verification exposed an additional assumption in the harness: an inline style load callback remained pending even though computed spacing had changed. The spacing helper now checks the inserted stylesheet directly. A fixture measures the actual spacing without enabling page scripts.

The maintained checker now verifies visible labels as well as counts and geometry. Deliberately fragmented labels must fail even when a page has no overflow. Browser accessibility snapshots can inspect which representation is exposed; they do not replace screen-reader use. This cycle remains self-review, with physical devices and screen readers unverified.
