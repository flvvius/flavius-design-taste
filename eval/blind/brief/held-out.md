# Held-out brief

Make two standalone HTML pages for a fictional municipal water-sampling laboratory, called Fieldwater. This subject and its data are held out from the design reference set. One page is a redesign of the provided existing sample queue. The other is a new public landing hero for the same organization.

The operator's task is to find today's samples, see the due time and status, open a sample and record a status. Preserve the supplied records, filter behavior, search, reset, dialog form validation, local status persistence, Escape/focus return, theme toggle and anchor destinations. Treat the existing JavaScript as the behavior contract. You may change its markup and styling while preserving its observable result. Keep its IDs and field names so the same checks can run. No auth or remote mutation exists. The records are test data, never production health evidence.

For the public hero, explain that Fieldwater collects and analyzes water samples for local councils. Primary action: request a sampling plan, using mailto:sampling@example.com. Secondary action: read the methods, linking #methods. The hero must have a working #methods explanation below it. No invented accreditation, turnaround, safety guarantee or testimonials. Mark the contact as a demonstration address. Audience is a council officer arranging monitoring, not a consumer buying a bottle of water.

Deliver screen.html and hero.html. Each must be self-contained, with no external fonts, images, libraries or services. Support 375/1280px, light/dark, keyboard focus, 200% text and reduced motion. Preserve useful color distinctions with text labels. No condition name, skill name or evaluation marker should appear in the rendered pages.

In notes.json, record start/end UTC, tool-call count, meaningful design decisions, checks run and known limitations. Do not inspect another condition's output or invent passing checks. The evaluator will apply identical checks after freezing your output.

Work limit for every condition: at most 18 tool calls and 15 minutes elapsed. Same inherited model, no delegation or model override. Keep prose short and spend the budget on the two pages. Stop when both pages and notes exist. This is a one-screen/one-hero task, not a whole site or research project.
